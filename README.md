## Deskripsi Aplikasi

Aplikasi Pengelolaan Kegiatan Kelas merupakan aplikasi sederhana berbasis web yang dibuat untuk membantu pengguna mengelola kegiatan kelas. Aplikasi ini memiliki fitur untuk menampilkan, menambah, mencari, menghapus, dan menghitung jumlah kegiatan.

## Teknologi yang Digunakan

- **HTML**: Membuat struktur halaman aplikasi.
- **CSS**: Mengatur tampilan dan desain aplikasi.
- **JavaScript**: Mengatur fungsi dan proses pada aplikasi.

## Fitur yang Berhasil Dibuat

1. **Menampilkan kegiatan:** Menampilkan seluruh daftar kegiatan yang tersimpan.
2. **Menambah kegiatan:** Menambahkan kegiatan baru ke dalam daftar.
3. **Mencari kegiatan:** Mencari kegiatan berdasarkan nama.
4. **Menghapus kegiatan:** Menghapus kegiatan yang dipilih.
5. **Menghitung jumlah kegiatan:** Menampilkan jumlah kegiatan yang tersimpan.

## Cara Menjalankan Aplikasi Secara Offline

1. Pastikan file `index.html`, `style.css`, dan `script.js` berada dalam satu folder.
2. Buka folder project aplikasi.
3. Klik dua kali file `index.html`.
4. Aplikasi akan terbuka menggunakan browser dan dapat dijalankan tanpa koneksi internet.
